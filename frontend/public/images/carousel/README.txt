Carousel images  -  home page gallery
====================================
Drop image files here  -  the home page gallery discovers them automatically
(via src/lib/getCarouselSlides.js). Filenames are sorted and shown as captions.

Supported image formats (any of these):
  .jpg   .jpeg   .png   .webp

Examples (any names; extensions must match the file):
  01.jpeg
  02.png
  photo-3.jpg

Next.js <Image> will optimize these formats when served from /public.
